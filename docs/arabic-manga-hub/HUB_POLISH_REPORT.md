# تحسين المركز الحالي وإصلاح نشر الفهارس

2026-11-07 — الفرع `feature/arabic-manga-hub`، الأساس `9745954bdcc9eb3c13ed758411c1c723e429c0cc`.

## النطاق والمنفذ

تعديل مكونات Classic الموجودة، دون إنشاء مركز أو محرك بحث أو تنزيل بديل. الأقسام المرئية Search وSites وDownloads، والبحث هو الافتراضي عند فتح المركز من القائمة الجانبية. حُذفت وجهة My Library غير المنفذة من التنقل؛ الاختيارات الدائمة أصبحت لوحة داخل Search، مع الإضافة الفردية والجماعية كما كانت. العناوين والتعليمات والأخطاء الخاصة بالمركز بالإنجليزية؛ الأسماء الأصلية العربية تبقى كما هي بعزل اتجاه النص.

بطاقات Sites أصغر، بخلفيات وحدود وألوان من سمات Carbon الداكنة، وحالة مكتبة البحث والعدد المحفوظ وآخر نجاح وحالة التحديث. Update يستخدم نفس مدير التحديث لموقع واحد، وOpen Site يفتح الموصل الأصلي في Media List. Update All والتقدم والموقع الجاري والأوامر المنظمة متاحة من الأقسام الثلاثة. النتائج حسب المصدر، والتقريب داخل Advanced search. تفاصيل المصادر والتنزيلات الطويلة قابلة للتوسيع، مع بقاء أخطاء التخزين ظاهرة والتحكم والتأكيد الصريحين.

## السبب المثبت وحدود التشخيص

التحديث اليدوي والجماعي يستعملان FetchMangas الأصلي نفسه؛ لا يوجد حد 100 في مدير الفهرسة. MangaLover يستعمل زخرفة Madara للترقيم حتى انتهاء الصفحات المتاحة. لكن المسار الجماعي كان يرفض **المحاولة كلها** عند عنوان فارغ أو هوية متعارضة، ويرفض القوائم ذات التغطية الجزئية. يمكن لذلك إسقاط مئة مرجع مسجلة قبل العنصر 101، بينما يحفظ المسار اليدوي قائمة الموصل الخام. كان النشر يرفض كذلك قائمة مفيدة بمجرد غياب هوية قديمة، ولو احتوت مراجع جديدة.

أُضيف اختبار 399 مرجعًا بعنصر فارغ في الموضع101 وفشل قبل الإصلاح. هذا سبب برمجي قابل للإثبات، وليس تشخيصًا مثبتًا لاستجابة 3asq الحية التي أبلغ عنها المستخدم؛ لم تتوفر استجابات حية للمقارنة، ولم تُتجاوز قيود الشبكة أو حماية المواقع.

## سياسة النشر والحفظ

- Collect يتجاوز الصف غير الصالح وحده، ويزيل التكرار المطابق، ويحتفظ بأول ملاحظة صحيحة للهوية المتعارضة مع وسم التغطية partial وتسجيل عدد العناصر المستبعدة، دون تسريب روابط أو بيانات حساب. لا يصبح اكتمال الموصل برهان اكتمال المصدر.
- MergeCatalogObservation يدمج المراجع الجديدة السليمة مع كل الهوية القديمة الغائبة عندما لا يوجد دليل اكتمال. بذلك لا يحل فهرس ناقص أصغر محل قائمة أكبر. قد تبقى مراجع قديمة اختفت من المصدر؛ غيابها ليس تعليمات حذف.
- الاستجابة الفارغة غير المثبتة أو غير المدعومة لا تستبدل القائمة. لا تُنشر نتيجة نقل فاشل أو مهلة أو طلب أُلغي في وقت متأخر. البرهان الصريح الكامل يحتفظ بالسلوك السابق الخاص بالقوائم الأصغر/الفارغة المبررة؛ EngineArchiveSource الحالي لا يختلق هذا البرهان.
- النشر معاملاتي في MediaLists وSiteIndexMetadata وسجل المهمة، مع فحص المراجعة لمنع الكتابة فوق تحديث يدوي أحدث. count هو الحجم المحفوظ المدمج، وdiscovered عدد المراجع الصحيحة المرصودة في المحاولة الجديدة. lastSuccess يعني نجاح حفظ الملاحظات، وليس اكتمال الموقع أو سلامة صوره.
- لا قاعدة فهرسة ثانية ولا تغيير لترحيلات IndexedDB v6 أو SQLite v10. إعادة الفتح تقرأ الفهرس المقبول نفسه، وإشعارات المراجعة تبطل ذاكرة البحث المشتقة وكاش Media List.

- SQLite والاستعادة تحت ثنائي Electron المثبت: 31 فحصًا ناجحًا، بما فيها SIGKILL والمخطط v10 وعضوية التشغيل والإيصالات والميزانيات.
- تكامل Electron:178 فحصًا ناجحًا، تشمل مقارنة حقيقية لشيفرة MangaLover مع HTML معزول لأربع صفحات399 عنوانًا ثم صفحة فارغة: حفظ398 رغم عنوان فارغ، وحفظ399 يدويًا، ثم إبقاء399 عند تحديث جماعي ناقص. لا طلبات حية.
- نشر IndexedDB الحقيقي: فشل المعاملة والتحديث اليدوي الأحدث والإلغاء تحفظ الفهرس السابق، والقوائم الجزئية تصبح قابلة للبحث، وإعادة تحميل العارض تستعيد المواقع الناجحة وتبقي المرشحة غير المنشورة منفصلة.
- الواجهة: Search افتراضي، ثلاثة أقسام، فتح المواقع ومحدد الموصلات والمفضلة ومرشح Media List السابق، تقريب البحث، اختيارات دائمة داخل Search، الإضافة الفردية والجماعية، pause/resume/cancel وعضوية التشغيل الثابتة. تحديث موقع منفرد وUpdate All لا يجلبان فصولًا أو صورًا.

- روجعت لقطات Search وSites في Classic الداكن داخل Electron/Linux. لا يعد ذلك اختبار Windows جديدًا.
- كانت إخفاقات Electron أثناء الاستكمال في تجهيز العينة: تكرار تهيئة نطاق إعدادات الموصل، وبدء تحديث بعد مهمة تُترك معلقة عمدًا لاختبار إعادة الفتح، وغياب تسجيل ArrayExtensions الذي يقوم به إقلاع المحرك الفعلي. عُزل نطاق إعدادات العينة وأُصلح ترتيب تجهيزها واستيراد التهيئة؛ لم تُخفف أقفال التطبيق أو قواعد استعادته لجعل الاختبارات تنجح.

## المتبقي ونقطة التوقف

لم يُضف نظام بيانات وصفية أو أغلفة أو أعداد فصول؛ الفهرس الحالي وSearchRow يحملان الهوية والعنوان، ولا توجد فيهما هذه الحقول الجاهزة للعرض. لا تُخترع معلومات ولا تُرسل آلاف طلبات إثراء ضمن تحديث القوائم. تبقى هذه الميزات، والمجموعة المحلية وتحديث manifests المكتملة واعتماد اتجاهات المصادر، للمراحل اللاحقة بعد المراجعة.

لا تغيير لمحرك تنزيل الصور والفصول أو ArchiveManager أو SQLite v10 أو عضوية القائمة أو ميزانية5/20 أو احتياطي50GiB. البيانات والجلسات والإيصالات باقية. مشاكل MangaTek/3asq الحية ليست معلنة محلولة؛ يلزم اختبار المستخدم المصرح به. الأرشفة الشاملة ما زالت تجريبية وخارطتها مستقلة؛ لا تشغيل غير محدود أو بدء تلقائي أو دمج في master.
